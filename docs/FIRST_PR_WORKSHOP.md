# First PR workshop: 15 minutes

1. Minutes 0-2: Explain that a repo is a shared project and an issue is one small task.
2. Minutes 2-4: Open the starter issue list and choose one labeled `good first issue`.
3. Minutes 4-6: Fork the repo, clone it, create a branch, and run `npm install` then `npm run dev`.
4. Minutes 6-9: Make one visible change, such as correcting a label or adding an accessible name.
5. Minutes 9-11: Run `npm run lint` and `npm run build`.
6. Minutes 11-13: Commit with `git add . && git commit -m "Fix: describe the change"`, then push.
7. Minutes 13-15: Open a PR, link the issue, describe the test, and add a screenshot when relevant.

Remind everyone: no secrets, one issue per PR, and their PR must contain their own work.
