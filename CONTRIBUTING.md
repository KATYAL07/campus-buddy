# Contributing

This project is exclusively for current Bennett University students participating in the GDG Bennett On Campus event. Students from other institutions must not contribute to the app, comment on campus content, or open participation PRs. GitHub repository visibility does not grant access to the student community.

1. Fork the repository on GitHub.
2. Clone your fork: `git clone YOUR_FORK_URL`.
3. Enter the folder and create a branch: `git checkout -b fix/short-description`.
4. Run `npm install` and `npm run dev`. Demo mode needs no secrets.
5. Comment on one starter issue and wait to be assigned.
6. Make the change, then test it with `npm run lint` and `npm run build`.
7. Commit your own work: `git add . && git commit -m "Fix: short description"`.
8. Push the branch: `git push -u origin fix/short-description`.
9. Open a pull request and describe the change.

Rules: one issue per PR. Your PR must contain your own commits. Include a screenshot for UI changes. Low-effort, automated, or whitespace-only PRs are marked as spam and do not count toward Hacktoberfest. Contributors never need a secret and must never commit one. Only Bennett University students may be assigned issues or have contributions accepted for this event.
